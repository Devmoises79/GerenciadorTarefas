### ✅ Gerenciador de Tarefas em C# (Console)
Este é um aplicativo de linha de comando desenvolvido em C# para gerenciar tarefas. Ele permite que o usuário adicione, liste, conclua e remova tarefas de forma simples, prática e interativa.

## 🧾 Funcionalidades
- ➕ Adicionar tarefa com descrição personalizada

- 📋 Listar todas as tarefas cadastradas com status (Pendente ou Concluída)

- ✅ Marcar tarefa como concluída usando o ID

- ❌ Remover tarefa do sistema

- 🔄 Interface de menu interativo em loop contínuo

## 💻 Tecnologias Utilizadas
- C# (.NET Core ou .NET Framework)

- Aplicação de linha de comando (console)

## ▶️ Como Executar
Crie um novo projeto C# (modo console) no Visual Studio, Visual Studio Code ou terminal:

```bash

dotnet new console -n GerenciadorDeTarefas
cd GerenciadorDeTarefas
```


Compile e execute o projeto:

```bash
dotnet run
```
## 🧠 Conceitos Abordados
- 📌 Programação Orientada a Objetos
Criação da classe Tarefa com propriedades (Id, Descricao, Concluida)

- 📌 Listas e Manipulação de Coleções
Uso de List<Tarefa> para armazenar tarefas em memória

- 📌 Estrutura de Controle
Laços while, switch-case, if-else para navegação de menu e controle de fluxo

- 📌 Métodos e Modularização
Funções específicas para cada ação: AdicionarTarefa, ListarTarefas, ConcluirTarefa, RemoverTarefa
